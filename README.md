# Wisdom Infotech

A responsive educational website built using HTML, CSS, and JavaScript. The project is designed for a coaching institute, providing information about courses, training programs, faculty, and contact details through a modern and user-friendly interface.

## 📖 About The Project

Wisdom Infotech is a frontend project developed for a coaching institute to establish a strong online presence. The website provides students with easy access to information about courses, training programs, institute services, and contact details.

In addition to the main website, I also developed an Admin Dashboard that enables efficient management and monitoring of institute-related information through a dedicated interface.

The project demonstrates my ability to build complete frontend solutions, including both user-facing websites and administrative dashboards.
